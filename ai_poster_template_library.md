# AI Poster Template Library

## Purpose

This file defines reusable **visual-only poster templates** for an AI-generated poster tool.

A template controls:
- Composition
- Visual hierarchy
- Layout
- Lighting
- Background treatment
- Decorative language
- Typography style
- Image/hero placement
- Color mood
- Depth and finishing

A template MUST NOT contain fixed event-specific content such as Pongal, Diwali, birthdays, company names, dates, prices, or specific people.

The poster generator should combine:

`SELECTED_TEMPLATE + USER_REQUEST + USER_ASSETS`

The user's request provides the actual content. The selected template provides the visual art direction.

# Template Selection Rules

When the user selects a template:

1. Preserve the selected template's composition.
2. Adapt the user's requested content into the template.
3. Do not blindly copy every visual object from the template.
4. Keep the main subject appropriate to the user's request.
5. Preserve visual hierarchy.
6. Preserve the template's lighting direction.
7. Preserve the template's overall composition.
8. Adapt colors when the user's request specifies a brand palette.
9. Keep important text readable.
10. Never allow decorative elements to overpower the main message.
11. Maintain the requested poster aspect ratio.
12. Generate a cohesive finished poster rather than a collection of disconnected elements.

# Template Priority

When combining a user request with a template, use this priority:

`User content > User brand requirements > Template composition > Template decorative details`

The template should control **how the poster looks**, not **what the poster says**.

# Quality Requirements

Every generated poster should aim for:

- Strong visual hierarchy
- Clear focal point
- Readable typography
- Balanced composition
- Appropriate negative space
- Consistent lighting
- Realistic depth
- Cohesive color palette
- Professional advertising quality
- High-detail rendering
- Print-quality visual finish

# Important AI Text Rule

Do not invent additional event information, company information, dates, prices, addresses or claims that were not provided by the user.

When exact text is supplied, preserve it as accurately as possible.

# Recommended Template Metadata

For implementation, each template can additionally store:

```json
{
  "id": "radial-festival",
  "name": "Radial Festival Sunburst",
  "category": "Indian Festival",
  "style": "premium",
  "composition": "radial",
  "recommended_aspect_ratios": ["2:3", "4:5", "1:1"],
  "prompt": "TEMPLATE PROMPT HERE",
  "preview": "template-preview-image"
}
```

The `preview` should be a generated example image showing the composition, not a fixed poster that restricts the user's content.
